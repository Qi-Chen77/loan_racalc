# 贷款重定价计算器

[![Test and deploy](../../actions/workflows/test.yml/badge.svg)](../../actions/workflows/test.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

一个基于实际还款日期和利率变化重新计算月供的网页，可直接部署到 GitHub Pages。

## 功能

- 根据当前剩余本金重新计算固定月供
- 支持在两个还款日之间变更利率
- 区分合同还款日与实际还款日
- 支持周末顺延和不调整两种日期规则
- 支持 ACT/365 和 ACT/360 计息
- 支持不规则到期日和自动调整尾款
- 可设置最后一期与倒数第二期的允许差额上下界
- 展示完整还款计划，包括利息、本金及剩余本金

## 使用方法

填写以下贷款信息：

- 剩余本金及余额日期
- 原利率、新利率及生效日期
- 每月还款日及最终到期日
- 末期允许差额的下界与上界

点击“计算新月供”后，页面会显示新月供、下次还款日、最后常规还款日、最终尾款及完整还款表。

末期差额按以下方式计算：

```text
|最后一期金额 − 倒数第二期金额|
```

计算器会在月供精确到分的前提下尽量减小该差额，并确保结果大于或等于下界、严格低于上界。

## 数学模型与求解

### 1. 日期与现金流

设余额日为 $t_0$，实际还款日依次为

$$
t_1\le t_2\le\cdots\le t_N.
$$

每月先生成合同还款日；如果指定日期不存在，例如 2 月 31 日，则取当月最后一天。随后按所选工作日规则得到实际还款日。到期日 $t_N$ 作为独立的最后一期日期。相邻合同日期经顺延后可能落在同一实际日期，因此这里允许等号。

利率生效日记为 $s$。每个计息区间采用左闭右开形式 $[t_{k-1},t_k)$，因此同一天不会被重复计息：

$$
r(t)=r_{\mathrm{old}}\quad\text{when }t<s,
$$

$$
r(t)=r_{\mathrm{new}}\quad\text{when }t\ge s.
$$

### 2. 分段利息

设第 $k$ 期的期初本金为 $B_{k-1}$，一年计息基数为 $D$。ACT/365 使用 $D=365$，ACT/360 使用 $D=360$。

将 $[t_{k-1},t_k)$ 按利率生效日切分成若干子区间，子区间天数为 $d_{k,j}$、适用年利率为 $r_{k,j}$。该期利息为

$$
I_k
=B_{k-1}\sum_j\frac{r_{k,j}d_{k,j}}{D}.
$$

定义该期本金增长因子

$$
q_k=1+\sum_j\frac{r_{k,j}d_{k,j}}{D},
$$

则支付前应还余额为

$$
G_k=q_kB_{k-1}.
$$

### 3. 常规月供递推

设精确到分之前的固定月供为 $P$。对于最后一期之前的所有还款，余额递推为

$$
B_k=G_k-P=q_kB_{k-1}-P,
\qquad k=1,\ldots,N-1.
$$

最后一期不再强制支付 $P$，而是支付当时的全部应还余额：

$$
F(P)=G_N=q_NB_{N-1}.
$$

因此最终支付 $F(P)$ 后有

$$
B_N=F(P)-F(P)=0.
$$

这保证最后一期始终自动清零。

### 4. 尾款差额约束

倒数第二期是常规月供 $P$，所以带符号的尾款差额定义为

$$
\Delta(P)=F(P)-P.
$$

页面展示和约束使用绝对差额 $|\Delta(P)|$。若用户输入下界 $L$ 和上界 $U$，可行月供必须满足

$$
L\le |\Delta(P)|<U.
$$

其中下界包含边界，上界不包含边界。

### 5. 为什么可以稳定求解

递推式对 $P$ 是线性的。展开后存在只由日期、利率和初始本金决定的常数 $A,C>0$，使得

$$
F(P)=A-CP,
$$

从而

$$
\Delta(P)=A-(C+1)P.
$$

所以 $\Delta(P)$ 关于 $P$ 严格单调递减，不会出现多个局部最优点。计算器通过二分法分别求解连续空间中的

$$
\Delta(P)=0,\qquad
\Delta(P)=L,\qquad
\Delta(P)=-L.
$$

第一组解对应最小绝对差额，后两组解对应允许区间的下边界。

### 6. 精确到分后的选择

实际月供必须是 $0.01$ EUR 的整数倍。计算器在上述连续解附近生成候选分值月供，重新模拟完整现金流，并保留满足

$$
L\le |F(P)-P|<U
$$

的候选项。最终选择 $|F(P)-P|$ 最小的候选项；若差额相同，则选择金额较低的月供。若不存在满足上下界的分值月供，则返回不可行提示，而不会给出违反约束的结果。

内部余额和利息保留完整浮点精度，常规月供固定到分；最后一期使用未四舍五入的剩余应还余额清零，页面展示时再格式化为两位小数。

## 测试

```bash
npm test
```

测试覆盖利率切换、日期边界、周末调整、闰年、不同计息方式、短期贷款及末期差额等场景。

## 构建单文件

```bash
npm run build
```

构建结果为 `dist/index.html`，其中已经包含页面样式和计算功能，可以作为单个文件发布或分享。

## 部署

仓库包含 GitHub Actions。代码推送到 `main` 或 `master` 分支并通过测试后，会自动部署到 GitHub Pages。
